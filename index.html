Improved Block Ordering and Frequency Selection for Reversible Data Hiding in JPEG Images

A Novel Approach to RDH in JPEG Images

Junhui He, Xinlu Pan, Hao-tian Wu, Shaohua Tang

School of Computer Science and Engineering, South China University of Technology

1. Introduction - Background

2/15

Reversible Data Hiding (RDH)

RDH techniques embed additional data into cover images in a way that allows:

  • Extraction of the embedded data
  • Lossless recovery of the original image

Applications

  • Military communication
  • Law forensics
  • Medical photography

Challenges for RDH in JPEG Images

  • Spatial domain schemes cannot be directly applied to JPEG images
  • Modifying DCT coefficients likely causes significant distortion
  • Existing techniques often suffer from:
    • Low embedding capacity
    • Large image distortion
    • Apparent increase in file size

1. Introduction - Research Problem

3/15

Current Techniques

RDH techniques for JPEG images are mainly based on:

  • Lossless compression
  • Code mapping
  • Modification of quantization tables
  • Histogram shift (HS)
  • ZRV pairs rotation

Limitations of Existing Approaches

Block ordering limitations:

  • Current methods sort blocks based only on the number of zero coefficients
  • Fails to consider that blocks with the same number of zero coefficients may result in different distortions
  • Distortion is related to both zero coefficients and distribution of AC coefficients

Frequency selection limitations:

  • Some methods make questionable assumptions about coefficient modification
  • Current methods require 63 bits of side information to record which frequencies are used

2. Related Works - Huang's Scheme

5/15

Huang's Scheme [41]

Uses histogram shift (HS) based RDH technique:

Data Embedding Process:

  • ±1 AC coefficients are expanded to carry secret data
  • Remaining non-zero AC coefficients are shifted toward histogram ends

For each DCT coefficient block Ci = {ci(u,v)}, embedding is described by:

c'i(u,v) = {
  ci(u,v) + sign(ci(u,v)) × b,   if |ci(u,v)| = 1
  ci(u,v) + sign(ci(u,v)),   if |ci(u,v)| > 1
}

Block Ordering Strategy:

  • Blocks with more zero coefficients take precedence for data hiding
  • Aims for better visual quality and smaller file size
  • Limitation: Cannot differentiate blocks with the same number of zero coefficients

2. Related Works - Hou's Scheme

6/15

Hou's Scheme [42]

Distortion Calculation:

If a non-zero coefficient with frequency (û,v̂) is changed, the distortion is calculated by:

Di(û,v̂) = (1/64)∑x=07∑y=07[Δfi(x,y)]2

Unit Distortion:

UDu,v = Du,v/Lu,v

Where Lu,v is the number of ±1 AC coefficients with frequency (u,v), and Du,v is the estimated total distortion.

Block Selection Strategy:

  • Based on estimated distortion
  • Estimated distortion: SDi = ∑(u,v)∈ΩDi(u,v)
  • Limitations:
    • Calculates distortion using only coefficients of selected frequencies
    • Assumes all bits to be embedded are value 1 (all non-zero coefficients modified)

2. Related Works - Wedaj's Scheme

7/15

Wedaj's Scheme [43]

Key Characteristics:

  • Uses the same HS-based embedding method as Huang's scheme
  • Uses the same block ordering approach as Huang's scheme

Embedding Efficiency Definition:

Ri = ∑n=14096E(i,n) / ((∑n=14096S(i,n) + E(i,n)/2) × Qi2)

Where:

  • i indicates the i-th frequency position
  • E(i,n) ∈ {0,1} represents whether the AC coefficient is embeddable
  • S(i,n) denotes whether it is shiftable
  • Qi is the quantization table entry

Frequency Selection:

  • Selects frequency positions in descending order of embedding efficiency
  • Uses the minimum number of positions needed to meet embedding capacity
  • Limitation: The selection may not result in the smallest embedding distortion

3. Proposed Scheme - Distribution Models

8/15

DCT Coefficient Distribution Models

The paper adopts the Laplacian distribution for modeling DCT coefficients:

Laplacian Cumulative Distribution Function (CDF):

Fu,v(x) = (1/2) + (1/2)sign(x)(1 - e-λu,v|x|)

Where λu,v (> 0) is the scale parameter.

Zero-valued AC Coefficient Ratio:

Pz(u,v) = (1/N)∑i=1NZi(u,v) = 1 - e-λu,v/2

Scale Parameter Calculation:

λu,v = -2ln[1 - (1/N)∑i=1NZi(u,v)]

Key Insight: The distribution models help estimate potential distortion more accurately by considering coefficient distribution patterns rather than just counting zero coefficients.

3. Proposed Scheme - Block Ordering

9/15

Improved Block Ordering Strategy

Key Improvements:

  1. Evaluates distortion on all AC coefficients within a block, not just selected ones
  2. More accurate estimation considering that each ±1 coefficient is modified with ~50% probability

Average Embedding Distortion Estimation:

Di = ∑u=07∑v=07[(1/2)Pc(u,v) + Ps(u,v)]Di(u,v)

Where:

  • Pc(u,v): probability of coefficient magnitude being equal to 1
  • Ps(u,v): probability of coefficient magnitude being larger than 1
  • Di(u,v) equals Q2(u,v) (squared quantization table element)

Simplified Formula:

Di = ∑u=07∑v=07(1/2)[e-λu,v/2 + e-3λu,v/2]Q2(u,v)

Result: Blocks with lower estimated distortion are prioritized for data embedding.

3. Proposed Scheme - Frequency Selection

10/15

Improved Frequency Selection Strategy

The paper recognizes:

  • Distortion caused by embedding varies with different frequencies
  • Capacity provided by frequencies with small distortion may not be large

Embedding Efficiency Definition:

Eu,v = Lu,v/Du,v

Where:

  • Du,v is the estimated distortion: Du,v = N[(1/2)Pc(u,v) + Ps(u,v)]Q2(u,v)
  • Lu,v is the estimated capacity: Lu,v = N × Pc(u,v)

Simplified Formula:

Eu,v = 2(eλu,v - 1)/((eλu,v + 1)Q2(u,v))

Frequency Selection Process:

  1. Sort 63 frequencies by their embedding efficiency values
  2. Select first K̂ frequencies by optimal search: K̂ = argminK∈{1,2,...,63}{T(K,m)}

Advantage: Only the number of selected frequencies (K̂) needs to be stored as side information, reducing overhead by 57 bits.

3. Proposed Scheme - Embedding Process

11/15

Data Embedding Procedure

Step 1: Decode JPEG

Partially decode the original JPEG image to obtain the quantized DCT coefficient blocks Ci and the quantization table Q

Step 2: Block Ordering

Calculate the scale parameter λu,v of each frequency using the derived formula

Sort DCT blocks in ascending order according to their estimated embedding distortion

Step 3: Frequency Selection

Calculate the embedding efficiency Eu,v of each frequency

Sort the frequencies in descending order according to their embedding efficiency

Step 4: Optimal Selection

According to the length of secret data m, select the first K̂ frequencies from the sorted frequencies by optimal search

Step 5: Data Embedding

Based on the block ordering, embed secret data into the AC coefficients with the selected frequencies in a block-by-block manner

Entropy-encode the modified DCT coefficients to obtain the marked JPEG image

3. Proposed Scheme - Extraction Process

12/15

Data Extraction and Image Restoration

Step 1: Decode Marked JPEG

Partially decode the marked JPEG image to get the quantized DCT coefficient blocks C'i and the quantization table Q

Step 2: Regenerate Ordering and Selection

Sort the DCT blocks and the frequencies using the same procedure as in data embedding (Steps 2 and 3)

Select the first K̂ frequencies from the sorted frequencies into a set Ω

Step 3: Data Extraction and Recovery

According to the block ordering, extract secret data from the non-zero AC coefficients with the frequencies belonging to Ω in a block-by-block manner until m bits are obtained

Re-encode the restored coefficients to get the cover JPEG image

Key Point: The extraction process is completely reversible, allowing for lossless recovery of the original image after data extraction, which is crucial for applications like medical imaging and legal forensics.

5. Conclusion

15/15

Key Innovations

More Accurate Distortion Estimation

Uses DCT coefficient distribution to better predict embedding impact

Enhanced Block Ordering

Prioritizes blocks with lower overall estimated distortion rather than just counting zeros

Efficient Frequency Selection

Selects frequencies based on embedding efficiency (capacity-to-distortion ratio)

Reduced Side Information

Requires only 6 bits for frequency selection versus 63 bits in previous methods

Verified Results

  • Superior Visual Quality: Average PSNR improvements of 0.3-0.7 dB across different quality factors
  • Better File Size Preservation: Reduces file size expansion by 270-730 bits on average
  • Balanced Performance: Consistently outperforms state-of-the-art methods regardless of quality factor or payload size

The improved block ordering and frequency selection methods provide a more effective framework for reversible data hiding in JPEG images, achieving better balance between visual quality, file size, and embedding capacity.
